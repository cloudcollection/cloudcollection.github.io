# Ziyi Zhou — Personal Website

A concise bilingual academic homepage, built from [luost26/academic-homepage](https://github.com/luost26/academic-homepage).

- [English](https://cloudcollection.github.io/en/index.html) · [中文](https://cloudcollection.github.io/zh/index.html)
- Real static pages for projects, modeling papers, experience and awards.
- Light, dark and system appearance, controlled by the settings icon.
- Self-hosted Source Serif 4 and Noto Serif SC fonts.

## Editing and preview

The HTML, CSS, images and PDFs are the website source. No React, npm or Jekyll build is required. Edit the corresponding files in en/ and zh/ together. Serve the repository with any static HTTP server, for example: python -m http.server 8000 --bind 127.0.0.1.

GitHub Actions publishes the repository as a static GitHub Pages site on pushes to main. The previous website remains recoverable through Git history.
